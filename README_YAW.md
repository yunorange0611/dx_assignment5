## 独立底盘行驶档自动接入Yaw

mode0、左拨杆上、五通道回中300ms底盘解锁后，自动仅使能已填写固定零点的Yaw；右拨杆位置不参与解锁。先回0，再由左杆横向控制。左杆竖向仍前后，右杆横向仍底盘转向。不再需要命令5。退出上档撤销这条Yaw使能；关控/失联停止，重新回中后恢复。其他四轴不自动使能；底盘不等Yaw成功。

此独立Yaw使能不再依赖整臂hardware_confirmed，仍检查自身配置、在线、校零、角度/温度和核心故障。固定零点-1时不自动使能。mode5/6仍是FM调参，未改为遥控驱动。原命令5/6保留维护用途。

mode5/6 也已和整臂健康拆开：只要求 Yaw 自身在线、已校零、无故障、反馈新鲜、温度正常，以及 CAN1 无 Transport/Timing 故障；其他关节在线/校零/故障、整臂 `hardware_confirmed`、底盘状态都不再阻塞 Yaw 调参。`kYawSafetyConfirmed` 仍只影响 FM 在线半幅申请；mode5/6 使用 `yaw_config.h` 的静态限位（当前 ±85°）。

# Yaw固定车头零点（当前入口）

失能并对正车头后，在FreeMASTER「第6批 Yaw线束中位与软限位」分组读取 `g_arm_status.joint[0].raw_encoder`（0..8191）。将该整数填入 `2User_Driver/Arm/yaw_config.h` 的 `kYawZeroEncoder`，重新编译、烧录并刷新FM符号。当前已按实测填入 `6352`；`-1` 表示尚未填写，保留原人工校零；不把0当作已测零位。

填写后首次反馈自动建立相对固定零点的坐标，`fixed_zero_encoder` 显示生效配置，`calibrated=1`；命令2不会覆盖固定Yaw零点。其他四轴仍需原校零。断电不得额外绕整圈，固定零点方案适用于零点附近小于±180°的实际行程；拆装/跳齿后重新标定。

0档用命令5仅使能Yaw（6仅失能）；或原整车开控入口。成功使能后 `homing=1`，参考角从当前位置按yaw_config.h速度/加速度向0运行，到零点附近后接受位置/遥控目标。mode5速度环调试显式接管回零。未开控时不出力，现有开控确认、反馈和关控条件保留；命令写入不代表使能成功，看last_result/enabled。独立遥控需左上+回中解锁，右拨杆位置不参与；不能用上档代替关控。

## 独立底盘左横直控

当前 `kChassisIndependent=true` 时，0档解锁后（`independent_armed=1`、左拨杆上）左横直接积分 Yaw 目标：`yaw_direct_target_deg` 从当前角开始，按 `max_speed_deg_s` 增长，限制使用 `arm.yaw_limits()` 的线束软限位；未配置限位时退回 `kYawConfig` 的 -85..85°/10deg/s。该路径不使用正常行驶姿态包络，不能称为碰撞保护。

Yaw 必须在线、已校零、已使能且无故障，直控才生效；固定零点轴首次开控会先回零（`homing=1`），回零期间左横不推进目标，回零完成后再接受直控。未使能时底盘照常驱动，Yaw 不动。只使能 Yaw 用 `g_robot_debug_command=5`，只失能用6，不影响其他关节。激活时目标从当前角开始；松开左横保持当前目标，不回中。关控、翻车、遥控失联、功率停车或离开上档会立即撤销直控，Yaw 按统一策略失能（通常不主动回中）；恢复要重新回中解锁并使能Yaw。

观察 `g_robot_status.yaw_direct_active`、`yaw_direct_target_deg`，以及 `g_arm_status.joint[0]` 的 `raw_encoder/fixed_zero_encoder/homing/position/target/velocity/effort`。

静态软限位在yaw_config.h的min_deg/max_deg，当前按实测右边界留余量设为±85°；在线对称半幅为tune_yaw_half_range_deg，仍要求kYawSafetyConfirmed和有效反馈/校零。`kYawSafetyConfirmed`仍为false时，mode5/6和独立直控使用静态±85°，但FM在线半幅申请不会生效；不改机械臂其他参数。

# Yaw限位与运行时调参

CAN1 GM6020电压模式，ID1，反馈0x205，输出0x1FF第一槽，effort单位为电压原码（满量程按±25000，手册可到±30000）。Yaw由原 `ArmControl / Robot_Execute / arm_task` 闭环并发送，没有第二个驱动或线程。与底盘共用 `Debug/Release` 整车固件，mode5/6选内环或双环，不换固件。

C板在底盘，Yaw相对角和速度来自6020编码器/rpm，不能用底盘IMU代替。没有滑环，断电后人工整理线束并对齐可重复的自然中位，再显式校零；任意上电姿态不当零点，软件不能识别断电期间额外扭转的整圈。

## 修改入口

| 内容 | 入口 |
|---|---|
| 模式、ID、比例、方向、静态范围与确认 | `2User_Driver/Arm/yaw_config.h` |
| 制动余量/减速度、目标领先约束 | 同文件Yaw限位参数 |
| 在线线束半幅 | `tune_yaw_half_range_deg` |
| 在线位置P、速度PI | `tune_yaw_position_kp`、`tune_yaw_velocity_kp`、`tune_yaw_velocity_ki` |
| 测试输出上限 | `tune_yaw_voltage_limit_raw`，电压原码 |
| 静摩擦前馈 | `tune_yaw_friction_ff_raw`，电压原码；0 关闭 |
| 速度/位置目标 | `tune_yaw_speed_deg_s` / `tune_yaw_target_deg` |
| 独立底盘直控使能/失能 | `g_robot_debug_command=5` 只使能Yaw；`=6` 只失能Yaw |

`kYawSafetyConfirmed`等确认默认false。约1:1传动、方向、实际软限位、可靠制动与电压输出须逐项实测；当前右侧实测约-87.9°，静态运行限位暂设±85°，但仍不能把暂定值当作完整安全行程。在线参数只存RAM，确定后写回源码。

`tune_yaw_friction_ff_raw` 只在Yaw为电压模式时叠加到速度环输出，用于顶过静摩擦死区。mode5速度测试中按目标速度方向整幅叠加，目标反向同拍翻号、写0同拍清零；目标反向或非零变0时还会清一次速度环积分。mode6位置环和正常控制中只在有规划参考速度时叠加，并按 `|reference_velocity|/1deg/s` 平滑到整幅；手碰而目标没动时参考速度为0，前馈为0，不会整幅翻号造成抖动。先保持速度P较低，逐步加前馈找到刚好能动的值，再加P；前馈过大也会造成过冲/抖动。

## 线束中位和半幅

全局关控并确认失能，整理线束到人工中位并保持静止。命令2在mode5/6只校Yaw，在0档针对全部五轴；两pitch如参与必须联合校零。检查 `g_arm_status.last_result`，不能只看命令已清0。

直接写 `tune_yaw_half_range_deg`，范围为[-half,+half]；原owner在数值变化时检查后应用，日常不用填限位序号。要求关控、反馈新鲜已校零且静止，范围合法且不超过已确认静态上限，实际角/目标/参考均被包含并留足制动余量。看 `g_yaw_limit_status.result/ready/active_half_range_deg`。拒绝后不迟到执行，修正原因后需再次明确修改输入；首次有效限位前正常Yaw/整车放行禁止。

生效版本同时用于遥控目标、姿态包络与内层限位；任务间用 `Yaw_GetLimitStatus()`，`ArmStatus.updated_ms`和`yaw_limit_version`用于核查发布时间与核心版本。不写只读状态强行放行。

## 速度内环与位置双环

| robot_tune_mode | 功能 | 目标 |
|---|---|---|
| 5 | 跳过位置外环，调速度PI | `tune_yaw_speed_deg_s` |
| 6 | 位置P＋速度PI | `tune_yaw_target_deg` |

底盘停止、机构有支撑；调参不再由固件强制拨杆位置，但上车应保持五通道回中并等实际静止；右拨杆位置不强制。按 **速度0/位置对齐当前角 → 切mode → 确认目标0或对齐当前角 → 写小目标**；没有单独 enable，非零速度或位置目标即执行，写0停止。切档会清历史并重新对齐位置目标。速度测试最大5deg/s，测试输出上限25000电压原码（默认25000）且受编译/已生效上限约束；目标须在生效线束软限位内。速度PI的Kp/Ki单位是电压原码/(deg/s)和电压原码/deg，不是mA；25000原码是本次调试上限，不等于已完成热/机械安全验收。

运行中可直接改P/PI/输出限幅，速度/位置目标会保留，不需要先把目标写0；查看 `g_robot_tune_status` 参数结果和实际值。真实角边界、目标领先、电压输出和反馈保护继续生效。速度环稳定后在同固件切6档调位置P。

把速度/位置目标写0或回0档停止Yaw调参运动，已使能Yaw按现有策略回到当前位置保持，其他已使能轴保持；切档不会自动使能其他四轴。全局关控/失联/故障按核定策略失能，零输出不是机械锁止。退出先目标0、停稳、mode=0，再正常模式停稳回中后命令4恢复遥控。

## 限位与输出边界

核心按真实角/速度、保守减速度和提前余量限制向外速度，保留朝内制动；越界故障余量与提前制动余量不同。行驶包络同时约束目标、参考和内层速度；新包络排除实际角/目标/参考时请求停车，不强拉回边界。未确认轮静止前不放宽已有较窄包络。

PI按最终安全/电压输出限幅后的提交值抗饱和，发送失败由原owner锁存并取消旧帧。限速不等于已验证制动距离，入队不等于电机执行。带载前双方确认Yaw撤力后的整臂/线束行为。

### CAN发送只读诊断
`g_can1_yaw_tx_debug`在CAN1发送任务调用HAL后记录GM6020命令组（0x1FE/0x2FE/0x1FF/0x2FF）的精确载荷。submitted仅代表HAL接受邮箱提交，不证明指定电机执行；cancelled/expired/failed分别记录取消、过期和提交失败。seq为偶数且读取前后一致才是完整快照。data[0..1]为ID1的有符号大端指令。诊断不改变目标或协议。
用户提供的GM6020 V1.0（2018.11）手册明确指定电压命令0x1FF/0x2FF、±30000；当前配置已切为电压协议0x1FF，代码按±25000原码封顶，实际可用上限仍需核对实物固件和电机手册。effort/PID单位是电压原码，不是mA，不能沿用电流模式参数。


### mode5/6 在线参数更新
